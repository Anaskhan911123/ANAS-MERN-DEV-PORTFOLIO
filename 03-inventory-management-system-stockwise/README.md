StockWise

A MERN stack app for managing inventory records, stock levels and stock activity.

Features
Inventory records: add, view, update, delete
Search and filter items
Stock management: stock in / stock out
Stock activity log
Dashboard overview
Reports with charts
Tech Stack

MongoDB · Express · React (Vite) · Node.js

Setup

Server

bash
cd server
npm install

Create server/.env:

PORT=5000
MONGO_URI=your_mongodb_connection_string
bash
npm run dev

Client

bash
cd client
npm install
npm run dev
